# AtmosDemo
Template code for the 2026 HSL raytracing Dawg Daze event

# Setup
WSL 2 recommended 

Create a virtual python environment, then do:

```
pip install opencv-python
pip install taichi
pip install pillow
```

# Running

```python demo.py``` will create output.png and debug.png  

output.png will be considered for physics and accuracy  
debug.png will be considered for artwork
